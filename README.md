- 🏗️ &nbsp;**End-to-end ownership** — from idea to production, solo or in a team
- 🤖 &nbsp;**AI integration** — multi-agent systems, RAG pipelines, LLM workflows (Anthropic SDK, Mistral, Mastra AI, ElevenLabs, AssemblyAI)

- ☁️ &nbsp;**Cloud & DevOps** — AWS (EC2, S3, Lambda, RDS) · Docker · Kubernetes · CI/CD · GitHub Actions
- 📦 &nbsp;**Open source** — published packages on npm, CLI tools, developer utilities
- 🔐 &nbsp;**Security** — zero-knowledge architecture, AES-256-GCM, JWT, OAuth 2.0
- 📝 &nbsp;**Writing** — engineering articles at [alphadevking.medium.com](https://alphadevking.medium.com)
- ⚡ &nbsp;**Fun fact** — I love exploring new frontiers and building on existing standards
